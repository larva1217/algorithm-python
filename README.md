# Python Algorithm

## 📚 학습 내용

- 구현 (Implementation)
- 그리디 알고리즘 (Greedy)
- 탐색 알고리즘 (Search)
  - 순차 탐색
  - 이진 탐색
- 정렬 알고리즘 (Sorting)
  - 선택 정렬
  - 삽입 정렬
  - 퀵 정렬
- 재귀 함수 (Recursive Function)
- DFS / BFS
- 다이나믹 프로그래밍 (Dynamic Programming)
- 최단 경로 알고리즘 (Shortest Path)
  - 다익스트라 알고리즘
- 그래프 알고리즘 (Graph)
- 기타 알고리즘 문제 풀이
